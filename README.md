# wepost.

Simple social media web app built with React, TypeScript, and Laravel API.

## Features

- Authentication
  - Login
  - Register
  - Protected routes
  - Guest only routes

- Posts
  - Create post
  - Update post
  - Delete post
  - Show post
  - View all posts
  - User profile posts

- UI
  - Dark modern design
  - Responsive layout
  - Sidebar navigation
  - Bottom navigation mobile
  - Loading states
  - Toast notifications

---

## Tech Stack

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- React Hot Toast
- Headless UI
- date-fns

### Backend

- Laravel
- MySQL
- Laravel Sanctum / API Authentication
